# 1. Install Typst

## 1.1. For ubuntu on WSL
### 1.1.1. 公式バイナリ（Snap）
```bash
sudo snap install typst
```

### 1.1.2. Using Cargo（Rust）
```bash
cargo install --locked typst-cli
```

## 1.2. 日本語フォント
```bash
sudo apt install fonts-noto-cjk
```

## 1.3. Confirm version
```bash
typst --version
```
